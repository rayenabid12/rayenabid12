# مكتبة الرسومات المتحركة · RAYEN

خمس رسومات جاهزة بهوية الصفحة. كل فيديو جديد هو ملف واحد تكتب فيه: متى يظهر كل رسم، وماذا يقول، وأين يكون وجهك. ثم أمر واحد يصدّر الفيديو النهائي.

```
motion-kit/
  kit.css, kit.js        المكتبة (لا تحتاج تعديلها)
  compose.mjs            أداة التصدير
  videos/01-return.html  مثال كامل: فيديو العودة
  assets/                الصور
```

## التصدير

مرة واحدة: `npm install`، ويلزمك أيضًا ffmpeg على جهازك.

```bash
node compose.mjs videos/01-return.html                         # بدون تصوير: مكان الوجه فارغ
node compose.mjs videos/01-return.html --footage take-01.mp4   # بتصويرك وصوتك
node compose.mjs videos/01-return.html --frames 2,15,30        # صور ثابتة للمراجعة السريعة
```

للمعاينة: افتح ملف الفيديو `.html` في المتصفح، أو أضف `?t=15` لتجميد الثانية 15.

**التصوير:** لقطة واحدة متواصلة، عمودية 1080×1920، من منتصف الصدر، والعينان على خط الثلث الأعلى. البطاقة تقصّ لقطتك وحدها حسب التخطيط، فلا تحتاج قصّ الخلفية ولا شاشة خضراء. ابدأ الكلام من الثانية 0 تمامًا، لأن التوقيتات تُحسب من بداية الملف.

## بنية ملف الفيديو

```js
Kit.mount({
  duration: 43,
  layout:   [[0,'split'], [9.6,'full'], [12,'split']],   // التخطيط من كل ثانية
  zoom:     [[10.8,1.2], [12,1]],                       // تقريب مفاجئ على الوجه
  graphics: [ { t0:0, t1:3.6, type:'counter', ... } ],  // الرسومات
  subs:     [[0,1.7,'هذي كانت *صفحتي*']]                 // الترجمة
});
```

| التخطيط | الشكل |
|---|---|
| `split` | الرسم في الأعلى وبطاقة الوجه في الأسفل. هذا هو الأساسي |
| `full` | الوجه بملء الشاشة، للجمل القوية |
| `graphic` | الرسم وحده، وأكبر قليلًا |
| `pip` | وجه صغير في الزاوية، والرسم أكبر |

**قواعد الترجمة:** من كلمتين إلى أربع في كل سطر، والكلمة بين نجمتين `*هكذا*` تظهر على خلفية كوبالت. كلمة واحدة على الأكثر في السطر.

## الرسومات الخمسة

### 1. بطاقة · `card`
```js
{ type:'card', variant:'title', tag:'BACK · 01', title:'غبت *10 شهور*', sub:'سطر صغير اختياري' }
{ type:'card', variant:'tiles', tag:'BRAND SYSTEM', items:[{icon:'logo',label:'لوغو'}, {icon:'color',label:'ألوان'}, {icon:'voice',label:'صوت',hi:true}] }
{ type:'card', variant:'solid', tag:'INSIGHT', title:'الأساس قبل الواجهة' }
{ type:'card', variant:'end',   tag:'THE FOUNDATION METHOD', title:'نبني الأساس<br>قبل الواجهة', by:'ريان، مصمم براند استراتيجي' }
```
- `title`: الكلمات تظهر واحدة بعد واحدة.
- `tiles`: بطاقات صغيرة تظهر بالتتابع. الأيقونات المتاحة: `logo` `color` `type` `voice` `target` `price`.
- `solid`: لوحة كوبالت للفكرة المحورية.
- `end`: بطاقة النهاية.

### 2. شبكة البناء · `grid`
```js
{ type:'grid', tag:'CASE 01 · PARA ELIXEA', label:'قبل الشكل: *الأساس*' }
```
تظهر خطوط الشبكة، ثم دائرتان، ثم يمتلئ الشكل بالكوبالت، كأن اللوغو يُرسم أمام المشاهد. تحتاج 5 إلى 6 ثوانٍ، وإذا أعطيتها وقتًا أقصر تتسارع وحدها.

### 3. عدّاد · `counter`
```js
{ type:'counter', tag:'2021 — 2025', prefix:'+', to:40, label:'كليون', tiles:40, time:1.4 }
```
الرقم يعدّ، والمربعات تتلوّن معه. `tiles:0` لإخفاء المربعات، و`suffix:'%'` للنسب.

### 4. قبل وبعد · `compare`
```js
{ type:'compare', mode:'text', tag:'THE CLIENT', afterAt:2.2,
  before:{ label:'ASKS FOR', items:['لوغو','تصميم'] },
  after:{  label:'BUYS',     items:['*ثقة*','وضوح'] } }

{ type:'compare', mode:'wipe', revealAt:1.7,
  before:{ src:'../assets/old-feed.jpg', label:'قبل' },
  after:{  src:'../assets/new.jpg',      label:'بعد' } }
```
- `text`: عمودان. عناصر «قبل» تُشطب، وعناصر «بعد» تظهر بعلامة صح.
- `wipe`: صورتان، وخط كوبالت يمسح «قبل» ويكشف «بعد». تقدر تستعمل `html` بدل `src`.

### 5. مراحل المنهج · `method`
```js
{ type:'method', tag:'THE FOUNDATION METHOD', steps:[
  { name:'افهم', desc:'السوق والحريف', at:0 },
  { name:'قرّر', desc:'شنوّا باش تقول العلامة', at:2 },
  { name:'صمّم', desc:'الهوية ودليل الاستعمال', at:4 },
  { name:'رافق', desc:'بعد الإطلاق', at:6 } ] }
```
`at` هي الثانية داخل المشهد التي تبدأ فيها كل مرحلة، فاضبطها على اللحظة التي تنطق فيها اسم المرحلة. تعمل مع أي عدد من المراحل، مثل مراحل دراسة الحالة الخمس.

## طريقة العمل لكل فيديو

1. اكتب النص بالدارجة، وقسّمه إلى جمل.
2. صوّر لقطة واحدة متواصلة.
3. انسخ `videos/01-return.html` باسم جديد، واضبط التوقيتات على صوتك. أسهل طريقة: شغّل التصوير، وسجّل الثانية التي تبدأ فيها كل جملة.
4. صدّر بـ `--footage`، ثم أضف الموسيقى في برنامج المونتاج.

**قاعدة الإيقاع:** شيء يتغير كل 1.5 إلى 2.5 ثانية: رسم جديد، أو تغيير التخطيط، أو تقريب، أو سطر ترجمة.
