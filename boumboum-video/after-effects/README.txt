BALLON BOUM BOUM - AFTER EFFECTS PROJECT
=======================================

1. Install the 3 fonts in the "fonts" folder (double-click each > Install).
   Restart After Effects if it was open.
2. Open After Effects, then: File > Scripts > Run Script File...
   and choose "BuildBoumBoum.jsx" (keep it inside this folder).
3. The script builds the project and saves "BoumBoum.aep" in this folder.

What you get
- "Boum Boum Promo" main comp: 1080x1920, 30 fps, 13.5 s, with music + sound effects.
- Scenes folder: 01 Intro, 02 Pasteque, 03 Fraise, 04 Outro (each fully editable).
- Text layers, shape layers (bubbles, stripes, splash), product images and keyframes.
- "Logo control" / "Badge control" nulls move/scale their groups.
- Scene transitions are keyframed on the scene layers in the main comp.

If After Effects says "Scripts are not allowed to write files", enable:
Edit (Windows) / After Effects (Mac) > Settings > Scripting & Expressions >
"Allow Scripts to Write Files and Access Network".
